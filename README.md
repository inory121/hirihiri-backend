# 基于微服务开发的仿哔哩哔哩网站后端(hirihiri-backend)

## 技术栈

- 后端：
    - SpringBoot3 + SpringSecurity +JWT+ SpringCloudAlibaba + MybatisPlus等
- 数据库：
    - MySQL 8.0.40 + Redis + ElasticSearch
- 开发环境：
    - JDK17 + IDEA 2024.3.1.1 + Maven 3.9.9
